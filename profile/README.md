## Welcome to DNALinux GitHub page 👋

DNALinux is an open source project dedicated to making bioinformatics and computational biology more accessible, reproducible, and easier to use.

DNALinux began in 2003 in Argentina, with a simple idea: make bioinformatics software easier for researchers and students to install and use. The first release was a Linux distribution that bundled commonly used bioinformatics tools into a ready-to-use environment. By 2006, DNALinux had reached more than 3,000 users in 80 countries and was recognized as one of the early Linux distributions specifically designed for bioinformatics.

Over the years, DNALinux evolved from Live CDs, to virtual machines, and now to containers, cloud environments, and AI-powered bioinformatics tools.

Today, the project is being developed as a modern open platform for genomics and computational biology. Our repositories include curated bioinformatics containers, workflows, and tools designed to support reproducible analysis across different architectures and computing environments.

Our goal is to continue the original DNALinux philosophy, making powerful computational biology tools accessible to everyone, while building the infrastructure needed for the next generation of biological discovery.
